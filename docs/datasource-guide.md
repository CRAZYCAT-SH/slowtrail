## 快速开始

1. 启动应用（桌面版双击打开 / Docker 访问 `http://localhost:3000` / 开发模式访问 `http://localhost:5173`）
2. 点击顶部导航栏的 **「数据同步」** 进入数据源管理页面
3. 新增一个数据源并测试连接
4. 选择数据源和实例，设定日期范围，点击「拉取数据」
5. 返回 Dashboard 查看分析结果

整个流程约 2-3 分钟完成。

---

## 数据源类型

SlowTrail 支持三种数据源类型：

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **Kibana 代理** | 通过 Kibana 的 Console Proxy 访问 ES | 无法直连 ES、需经过 Kibana 鉴权的环境 |
| **直连 ES** | 直接连接 Elasticsearch REST API | ES 可直接访问的环境 |
| **Excel/CSV** | 从文件导入慢查询数据 | 离线数据、历史导出数据、非 ES 来源 |

## 新增数据源

在「数据同步」页面顶部的「数据源」区域，点击右上角 **「新增」** 按钮，打开数据源配置弹窗。

### 通用字段

所有类型共用以下基础字段：

| 字段 | 说明 |
|------|------|
| 名称 | 自定义名称，如"生产环境 ES"、"测试环境" |
| 类型 | 选择数据源类型（Kibana 代理 / 直连 ES / Excel/CSV） |
| 启用 | 是否在同步时可选用该数据源 |

---

### Kibana 代理模式

适用于通过 Kibana 访问 ES 的场景（大多数企业环境）。

**配置步骤：**

1. **填写 Kibana 地址**：输入 Kibana 的完整 URL，如 `http://kibana.company.com:5601`
2. **代理路径**：默认为 `/api/console/proxy`，一般无需修改
3. **认证信息**：填写 Kibana 的用户名和密码（可选，取决于是否开启认证）
4. **索引模板**：配置你的慢查询日志索引命名规则

**索引模板配置：**

索引模板决定系统搜索哪些 ES 索引。支持以下占位符：

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{YYYY}` | 四位年份 | 2024 |
| `{YY}` | 两位年份 | 24 |
| `{MM}` | 两位月份 | 01-12 |
| `{M}` | 月份（不补零） | 1-12 |
| `{DD}` | 两位日期 | 01-31 |
| `{D}` | 日期（不补零） | 1-31 |
| `*` | 通配符 | 匹配任意字符 |

**常见索引模板示例：**

```
按日切分:  mysql_slow_log-{YYYY}.{MM}.{DD}
按月切分:  logs-{YYYY}-{MM}
不切分:    mysql_slow_log
纯通配:    mysql_slow_log-*
```

配置完模板后，点击旁边的 **「预览」** 按钮，可以验证：
- 切分周期是否正确推断
- 实际存在的索引是否匹配

4. **测试连接**：点击弹窗底部 **「测试连接」**，确认能正常连通
5. **保存**：连接正常后点击 **「保存」**

---

### 直连 ES 模式

适用于可以直接访问 Elasticsearch 的场景。

**配置步骤：**

1. **填写 ES 地址**：输入 Elasticsearch 的地址，如 `http://es-host:9200`
2. **认证信息**：如 ES 开启了认证，填写用户名和密码
3. **索引模板**：同 Kibana 代理模式，配置索引命名规则
4. **测试连接** → **保存**

> 注意：直连模式没有代理路径配置项，其余配置与 Kibana 代理模式一致。

---

### Excel/CSV 导入

适用于从文件导入慢查询数据。

**配置步骤：**

1. **上传文件**：点击「选择文件」上传 .xlsx / .xls / .csv 文件（最大 50MB）
2. **选择工作表**：如果 Excel 有多个 sheet，选择包含慢查询数据的 sheet
3. **配置列映射**：将文件中的列与系统字段对应

**列映射说明：**

| 字段 | 必填 | 说明 |
|------|------|------|
| SQL 语句 | ✅ | 原始的慢 SQL 文本 |
| 查询耗时(秒) | ✅ | 查询执行时间，单位秒 |
| 时间戳 | 否 | 查询发生的时间（支持毫秒/秒时间戳或日期字符串） |
| 数据库名 | 否 | 执行 SQL 的数据库名 |
| 实例名 | 否 | MySQL 实例标识 |
| 锁等待时间 | 否 | 锁等待耗时（秒） |
| 扫描行数 | 否 | SQL 扫描的行数 |
| 返回行数 | 否 | SQL 返回的结果行数 |

上传后会显示数据预览（前 5 行），帮助你确认列映射是否正确。

4. **保存**：确认映射无误后保存

## 管理数据源

### 字段映射（高级选项）

ES 类数据源支持自定义字段映射。点击「高级选项」展开：

1. 点击 **「获取字段」** —— 系统会自动探测索引中的字段列表
2. 在下拉框中为每个系统字段选择对应的 ES 字段
3. 如不需要自动发现，也可直接手动输入字段名

**keyword 后缀**：ES 中 text 类型字段通常有一个 `.keyword` 子字段用于精确匹配。默认值 `.keyword` 适用于大多数场景。如果你的字段本身就是 keyword 类型，将此项留空。

### 编辑数据源

在数据源列表中点击对应数据源的 **「编辑」** 按钮，修改配置后保存。

> 注意：编辑时密码字段显示为 `******`，留空表示不修改原密码。

### 删除数据源

点击 **「删除」** 按钮。系统会询问是否同时删除该数据源已同步的数据：
- **保留数据**：仅删除数据源配置，已拉取的慢查询记录保留
- **同时删除数据**：配置和数据一并清除

> 注意：通过环境变量初始化的默认数据源不可删除，但可以编辑。

### 测试连接

- **编辑模式**：测试使用数据库中保存的真实密码
- **新增模式**：测试使用当前表单填写的配置

## 数据同步

数据同步是将远端（ES / 文件）中的慢查询日志拉取到本地数据库的过程。

### 同步操作

1. **选择数据源**：从下拉框选择一个已启用的数据源
2. **选择/输入实例名**：
   - 如果数据源支持实例枚举（Kibana 代理/直连 ES），点击「刷新列表」获取实例列表，然后从下拉框选择
   - 如果不支持枚举，手动输入实例名称
3. **选择日期范围**：
   - 使用快捷按钮选择「昨天」「近 3 天」「近 7 天」等
   - 或手动选择开始/结束日期
4. **覆盖选项**：勾选「覆盖已拉取数据」会重新拉取已有日期的数据（适合当天数据持续更新的场景）
5. 点击 **「拉取数据」**

### 同步结果

拉取完成后会显示结果摘要：

- **拉取记录数**：本次成功入库的慢查询条数
- **成功天数**：有数据且成功同步的日期数
- **跳过（已拉取）**：如未勾选覆盖，已有数据的日期会被跳过
- **无数据**：远端在这些日期没有慢查询记录
- **错误**：如有失败的日期，会显示具体错误信息

### 去重机制

系统以「数据源 + 实例名 + 日期」为唯一键：
- 同一个数据源的同一个实例在同一天的数据只保留一份
- 重复拉取（不勾选覆盖）会自动跳过
- 勾选覆盖时会先删除再重新拉取

### 多数据源协作

- 不同数据源的数据会合并到同一个本地数据库
- Dashboard 和统计分析会统一展示所有数据源的数据
- 可通过实例名、数据库名等维度筛选

## 同步历史与数据管理

### 同步历史表格

页面底部展示所有同步记录，包含：

| 列 | 说明 |
|----|------|
| 数据源 | 来源数据源名称 |
| 实例 | 数据库实例名 |
| 数据日期 | 慢查询数据的日期 |
| 记录数 | 该天拉取的慢查询条数 |
| 同步时间 | 执行拉取操作的时间 |
| 操作 | 可按条目删除 |

### 删除数据

- **按记录删除**：在同步历史表格中点击某条记录的「删除」按钮，精确删除某数据源/实例/日期的数据
- **清空所有**：点击统计栏的「清空所有」按钮，清除本地数据库的全部慢查询数据

### 数据库统计

页面中部展示：
- **本地数据条数**：当前数据库中的慢查询总记录数
- **数据库大小**：SQLite 数据库文件占用磁盘空间

## 常见问题

### 连接测试失败

**Kibana 代理模式：**
- 确认地址填写的是 Kibana（非 ES）的地址
- 检查代理路径是否正确（默认 `/api/console/proxy`）
- 确认用户有对应索引的读取权限
- 注意 URL 协议（http / https）

**直连 ES 模式：**
- 确认地址填写的是 ES 节点地址
- 检查网络是否可达（防火墙、VPN 等）
- 如有认证，确认用户名密码正确

### 索引模板预览显示"未匹配到索引"

- 检查索引模板拼写是否与实际索引名一致
- 使用 `*` 通配符适配索引名中的变化部分
- 确认选择的时间范围内确实有对应索引存在

### 拉取数据为空

- 在 ES 中确认该实例在指定日期范围内确实有慢查询记录
- 检查字段映射是否正确（特别是 `instance_name` 字段）
- 尝试扩大日期范围

### Excel 导入失败

- 确认文件格式为 .xlsx / .xls / .csv
- 检查文件大小不超过 50MB
- 确认必填列（SQL 语句、查询耗时）已正确映射

### 重复拉取数据翻倍？

不会。系统有去重机制，同一个「数据源 + 实例 + 日期」的数据只保留一份。如果需要更新已有数据，勾选「覆盖已拉取数据」选项即可。

## 推荐工作流

### 日常使用

1. 每天上午拉取前一天的数据（选择「昨天」快捷按钮）
2. 进入 Dashboard 查看概览和 TOP 慢 SQL
3. 通过趋势分析观察慢 SQL 数量变化
4. 使用指纹归类找出反复出现的问题 SQL

### 首次接入

1. 创建数据源并测试连接
2. 先拉取近 1 天数据验证是否正常
3. 确认无误后拉取近 7 天数据建立基线
4. 之后每天增量拉取

### 多环境管理

1. 为每个环境（生产、预发、测试）各创建一个数据源
2. 统一拉取后可在 Dashboard 通过实例名筛选
3. 对比不同环境的慢 SQL 差异
